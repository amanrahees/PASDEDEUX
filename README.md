# PASDEDEUX Ecommerce Platform

## Project description

**PASDEDEUX** is a full-stack ecommerce platform built with Django REST Framework (DRF) and Next.js.
The project follows a decoupled architecture where Django provides the REST API and business logic, while Next.js handles the frontend, UI, and server-side rendering.

The project is currently at the foundation stage. The infrastructure and application
structure are ready for feature APIs and business logic to be added incrementally.
